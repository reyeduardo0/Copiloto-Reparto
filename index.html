Asistente con IA (opcional)

La IA (Claude) entiende cualquier forma de pedir las cosas, incluso varias a la vez, y lee las etiquetas de los paquetes. Necesita cobertura y tu cuenta de la nube. Sin ella, la app funciona como siempre.

Privacidad: para la voz solo se envía tu frase y un resumen con números (cuántas paradas llevas, etc.), nunca tu lista de direcciones. Para leer una etiqueta se envía su foto, que incluye datos del cliente; la IA solo devuelve la dirección. Consulta con tu empresa si puedes usarlo.

Activar la IA en el servidor (una vez)
  1. Entra en platform.claude.com, crea una cuenta, añade saldo (con 5 $ tienes para mucho tiempo) y en «API Keys» crea una clave.
  2. En Supabase, abre tu proyecto → Edge Functions → Secrets y añade un secreto llamado ANTHROPIC_API_KEY con esa clave. La clave queda solo en el servidor: nunca la pongas en la app.
  3. Solo la cuenta reyeduardo0@gmail.com puede usar la IA. Para permitir otras, añade el secreto IA_CORREOS_PERMITIDOS con los correos separados por comas (incluye también el tuyo).
  4. En Authentication → Sign In / Providers, cuando ya tengas tu cuenta creada, desactiva «Allow new users to sign up» para que nadie más pueda registrarse.
  5. Opcional: añade IA_LIMITE_DIARIO con el máximo de consultas al día (por defecto, 300).
  6. Vuelve aquí y pulsa «Probar la IA».

Cuenta y copia en la nube

Guarda tus ajustes, notas, aparcamientos, repostajes, historial y la ruta del día en tu base de datos de Supabase. Con la misma cuenta en la tablet y en el ordenador, todo se comparte. Sin cobertura se guarda aquí y se sube al volver la conexión. Las fotos se quedan en este dispositivo.

Preparar la base de datos (solo la primera vez)
  1. Entra en supabase.com, abre tu proyecto y ve a SQL Editor → New query.
  2. Pega este código (botón «Copiar») y pulsa Run. Crea la tabla y las reglas para que cada usuario solo vea sus datos.
  3. En Authentication → URL Configuration, pon en «Site URL» la dirección de tu app publicada (por ejemplo https://tu-usuario.github.io/copiloto/), para que el enlace del correo de confirmación te devuelva a la app.
create table if not exists public.copiloto_datos (
  user_id uuid not null default auth.uid() references auth.users(id) on delete cascade,
  clave text not null,
  datos jsonb not null,
  actualizado timestamptz not null default now(),
  primary key (user_id, clave)
);
alter table public.copiloto_datos enable row level security;
drop policy if exists "ver lo mio" on public.copiloto_datos;
drop policy if exists "crear lo mio" on public.copiloto_datos;
drop policy if exists "cambiar lo mio" on public.copiloto_datos;
drop policy if exists "borrar lo mio" on public.copiloto_datos;
create policy "ver lo mio" on public.copiloto_datos for select to authenticated using ((select auth.uid()) = user_id);
create policy "crear lo mio" on public.copiloto_datos for insert to authenticated with check ((select auth.uid()) = user_id);
create policy "cambiar lo mio" on public.copiloto_datos for update to authenticated using ((select auth.uid()) = user_id) with check ((select auth.uid()) = user_id);
create policy "borrar lo mio" on public.copiloto_datos for delete to authenticated using ((select auth.uid()) = user_id);
grant select, insert, update, delete on public.copiloto_datos to authenticated;
revoke all on public.copiloto_datos from anon;

Conexión

Instalar la app (recomendado)

  1. Crea una cuenta gratuita en github.com (solo correo y contraseña).
  2. Pulsa «+» → «New repository», ponle de nombre copiloto, márcalo como Public y pulsa «Create repository».
  3. En el repositorio pulsa «uploading an existing file» y arrastra este archivo. Antes, cámbiale el nombre a index.html. Pulsa «Commit changes».
  4. Ve a Settings → Pages. En «Branch» elige main y pulsa «Save». En uno o dos minutos te dará una dirección como https://tu-usuario.github.io/copiloto/.
  5. Abre esa dirección en Chrome (en la tablet y en el ordenador), acepta el micrófono y el GPS una vez y en la tablet usa ⋮ → «Añadir a pantalla de inicio».

Tus datos no se pasan solos de la versión en archivo a la publicada: usa «Descargar copia» aquí y «Restaurar copia» en la nueva.

Mapas y navegación

Todo funciona sin clave ni registro: satélite oficial del Instituto Geográfico Nacional, direcciones con CartoCiudad (callejero oficial con números de portal), tráfico en directo de Waze y navegación con Waze o Google Maps.

Si CartoCiudad no encuentra una dirección, se prueba con OpenStreetMap.

Google Maps con clave (opcional, avanzado)

Solo si algún día quieres el mapa de Google, su tráfico dentro del mapa y Street View integrado. No es necesario: la app funciona completa sin esto.

Cómo conseguir la clave
  1. Entra en console.cloud.google.com con tu cuenta de Google y crea un proyecto.
  2. En «Facturación», asocia una tarjeta. Google la exige aunque tu uso quede dentro de la parte gratuita.
  3. En «APIs y servicios → Biblioteca», activa Maps JavaScript API y Geocoding API.
  4. En «Credenciales», crea una clave de API y pégala aquí.
  5. Muy importante: en la clave, restringe «Sitios web» a la dirección de tu app (por ejemplo tu-usuario.github.io/*) y limita las API a esas dos. Así nadie puede usarla desde otra web.
  6. En «Cuotas», pon un límite diario (por ejemplo 300 localizaciones y 100 cargas de mapa) para no llevarte sorpresas.

Qué puedes decir

No hace falta decirlo exactamente así: habla con tus palabras. La app ignora «oye», «por favor», «quiero», «vamos a»… y entiende sinónimos (añade, agrega, mete, apunta; parada, entrega, dirección, paquete).
